## Ref 01 — Teenage Engineering (teenage.engineering)  [anchor reference]

Captured: desktop 1440w + mobile 390w.

**Observed visual moves:**
- **Palette:** pure white background, near-black ink, **orange as the only accent** — applied
  to ~2% of pixels (a small `UPDATE` tag, version numbers `2.5 / 2.5 / 1.5`, one squiggle).
  Orange = highlight, never a fill.
- **Type as hero:** huge heavy grotesque headline, condensed, tightly packed, mixed sizes on
  a single line. Type carries the composition; imagery supports.
- **Nav = hardware markings:** tiny lowercase label clusters (`instruments / audio / designs`)
  with small icons; lowercase `teenage engineering` wordmark, quiet, top-left.
- **En-dash catalog naming:** `EP–133`, `EP–40`, `EP–1320`.
- **High-contrast sectioning:** stark white editorial → full-black product beauty shot. Big
  tonal jumps define sections.
- **Space + grid:** heavy negative space, everything aligned to a strict grid.

**What we take:** discipline, restraint, lowercase hardware labels, en-dash naming, type
confidence, grid rigor, orange-as-signal.

**What we deliberately change for CG:**
- Push orange from "2% spark" → a **confident warm accent** (still disciplined, but warmer
  and more present — matches CG's "warm editorial" brief).
- Swap stark pure-black → **softer near-black ink** on a warm off-white base (calmer, less
  fashion-brand, more premium-personal).
- Keep type strong but a touch more refined/editorial than TE's ultra-heavy display.

## Ref 02 — Surjith (surjith.netlify.app)  [HERO composition reference]
User note: "I like how Surjith used orange — take it as **hero section** inspiration."
Captured desktop 1440w + mobile 390w.

**Observed hero moves (what we borrow):**
- **Giant name as backdrop type:** "Surjith" set enormous in elegant italic serif, full-width,
  sitting *behind* the subject.
- **Subject cut out in front of the name:** he overlaps the type (sits on a stool over it),
  creating real foreground/background depth. Name still reads around him.
- **Orange justified by the subject:** his orange jacket + orange stool ARE the accent — the
  palette is earned by the image, not layered on. → For CG, **the robot is already orange**,
  so the same logic applies natively.
- **Punchline word in orange:** tagline "I do ux that drives," (white) → **"business growth"**
  (orange). The orange word is the payoff. Maps to a CG tagline.
- **Small top-left wordmark + role chip**, single CTA top-right ("Get in touch").

**Observed body moves:**
- Hero is **dark/moody** (near-black gradient) → body flips to **light editorial case-study
  cards** (big serif headlines on white). High-contrast sectioning, like TE.
- Occasional second accent (blue) used very sparingly inside case studies.

**What we take:** the **hero composition** (name-behind / subject-in-front / orange punchline
word) and the confident orange.
**What we change for CG:** brief is **light/editorial**, so likely a **light hero** using
Surjith's *composition* + TE's *light restraint* — the orange robot doing the accent work
instead of a photo. (Dark-hero-then-light-body is a fallback option to weigh in Phase C/I.)

## Ref 03 — Daylight (godaylight.com)  [color simplicity + section rhythm + scroll interaction]
User note: "squares and interaction — simple, sharp; orange usage simple; liked the landing
home page down to the subscribe section." Captured via scroll-driven frames (page ~16000px).

**Observed moves (what we borrow):**
- **Full-bleed orange hero** → then body transitions to a **warm cream/off-white** base. The
  orange is *spent* boldly in the hero, then the site calms into cream. (A "budget the orange"
  model: one saturated moment, then restraint.)
- **Mono uppercase micro-labels** as eyebrows: `HOW DAYLIGHT WORKS`, `STEP 1`,
  `A LOWER BILL EVERY MONTH`, `DAYLIGHT HANDLES EVERYTHING`. Small, tracked, technical.
- **Two headline styles:** an elegant **serif** for big statements ("A new way to power your
  home") AND a **rounded humanist sans** for step titles ("Subscribe to Daylight", "We install").
- **Numbered step narrative:** STEP 1 / 2 / 3 with lots of whitespace; content left-aligned,
  supporting visual right. Clean editorial rhythm — maps well to CG's Experience timeline.
- **The "squares"/interaction:** a **scroll-drawn orange line illustration** — an isometric
  diagram that draws itself as you scroll through the steps. Single orange stroke on cream.
  Minimal, sharp, delightful — a great model for CG's subtle scroll motion + the 3D/line accent.
- **Buttons:** solid black button ("Get your estimate") on cream; orange reserved for the nav
  CTA + device mockups. Orange contained inside product mockups rather than sprayed on layout.

**What we take:** the **cream editorial base**, mono step-labels, numbered-step rhythm, the
"budget the orange" discipline, and the **scroll-drawn line** interaction idea.
**What we change for CG:** hero is light (not full-bleed saturated orange) — the robot is our
saturated moment instead; keep one headline family + mono labels rather than serif+sans+mono
to stay more disciplined.

**Locomotive is generally known for (unverified here):**

- **Big confident type**, generous whitespace, minimal palette, restrained color.
- **Magnetic / cursor-reactive** interactive elements (buttons that pull toward the cursor,

**What we'd take (pending confirmation):** the *experience qualities* — smooth scroll feel,
magnetic hover on the CTA, calm reveal transitions — as motion-language inputs for Phase H.
Not the layout. Will confirm the specific bits CG liked before relying on this.

**User confirmed (2026-08-10) what they loved at Locomotive:**
1. **Calm reveal transitions** — sections/elements ease in smoothly on scroll.
2. **Smooth inertia scroll** — eased momentum scrolling.
3. **Overall minimal layout** — big type, whitespace, restrained palette.
→ These feed **Phase H (motion)**: gentle scroll-reveals + optional smooth-scroll, and
reinforce the minimal-layout direction already set by TE/Daylight.
