CG Robot — library

Everything the mascot can do, in one place. Two files — robot-lib.css + robot-lib.js — no dependencies, drop in anywhere. Declare a robot with an attribute, or build one in JS and call methods on it. Hover, click, and press the buttons — this page is live.

01 · expressions

12 expressions

Only eyes + mouth change. Head, antennas and ears are constant.

Every one carries a soft smile in the same shade rgba(25,21,18,.42) — the robot is never "smile off". surprised is the new one: wider sockets, small high pupils, and an open o mouth.

Breathing scales from transform-origin:50% 100% — the base of the head — so it swells upward like a chest rising, never a pulsing balloon. The exhale is longer than the inhale (45% in, 55% out), which is what makes it read as breath rather than a throb.

03 · one-shot events

Reactions you trigger

Fire on click, form submit, scroll-into-view, or any app event.

bot.wobble() · bot.nod() · bot.shake()
bot.jolt() · bot.pop() · bot.surprise()
bot.think(true) · bot.showHint(true)

surprise() is a composite: it switches to the surprised expression, plays jolt (a springy pop with overshoot), then settles back after 1.1s. That combination is what makes it read as a genuine reaction rather than a state change.

04 · cursor tracking

● head rotates up to 5°
● all three together = one reacting face

08 · usage

How to use it

<!-- declarative: auto-mounts -->
<div data-cg-robot
     data-size="40"
     data-expression="neutral"
     data-idle="breathe blink sway"
     data-hover="curious tilt"
     data-hint="optional annotation"
     data-follow="true"></div>

// programmatic
const bot = CGRobot.create({
  size: 150, expression: 'neutral',
  idle: ['breatheDeep','blink','sway'],
  follow: true, followTarget: heroSection,
});
heroEl.append(bot.el);

bot.setExpression('surprised');
bot.surprise();          // wide eyes + jolt, settles back
bot.think(true);         // bolt on
bot.gaze(-0.6, 0.2);     // aim the eyes
bot.lean(4);             // scroll-linked tilt
bot.showHint(true);

React port is mechanical: EXPRESSIONS becomes the props union, the controller methods become useEffect + handlers, and the SVG body moves into JSX unchanged. Same CSS file.
